# Hydrogen

A new programming language. Work in progress — design is being defined.

## Layout
- `spec/`     — language specification (grammar, semantics, type system)
- `docs/`     — design notes and decision records
- `examples/` — sample Hydrogen programs
- `tests/`    — conformance / regression tests

The implementation (compiler/interpreter) directory will be added once the
host language and architecture are chosen.
